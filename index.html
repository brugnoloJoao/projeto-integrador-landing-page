Uma torre de controle para a manutenção da sua planta

O PetroSync centraliza dados de sensores IoT e sistemas SCADA, aplica ciência de dados para prever falhas antes que elas parem a operação, e entrega tudo em dashboards que qualquer engenheiro de manutenção entende de cara.

A solução

TI e Automação Industrial, na mesma plataforma

O PetroSync nasceu para resolver um problema específico: dados de planta que ficam presos em sistemas SCADA isolados, sem virar decisão de manutenção a tempo. A plataforma faz essa ponte sem exigir a troca dos sistemas já instalados.

Escopo funcional

Seis módulos, um só sistema

Cinco módulos formam o núcleo obrigatório da plataforma. A Realidade Aumentada é entregável adicional — não trava a entrega principal.

API para ingestão, tratamento e disponibilização dos dados, com controle de acesso por perfil de usuário.

  • Conectores OPC UA (SCADA) e MQTT (sensores IoT)
  • Persistência de séries temporais e dados relacionais de ativos
  • Motor de regras para alertas de desvio operacional
  • Gestão de ativos, ordens de serviço e histórico de manutenção

Aplicação web responsiva para monitoramento em tempo real e gestão de manutenção.

  • Gráficos de tendência, status de equipamentos e mapa de ativos
  • Painel de alertas e notificações
  • Relatórios gerenciais com integração ao Power BI
  • Interface de gestão de ordens de manutenção

Hospedagem escalável com serviços gerenciados e entrega contínua.

  • Banco de dados, mensageria e armazenamento gerenciados (AWS, Azure ou GCP)
  • Escalabilidade automática para picos de eventos IoT/SCADA
  • Pipeline de CI/CD para deploy contínuo
  • Observabilidade: logs, métricas e saúde da aplicação

Modelos preditivos e indicadores de confiabilidade a partir do histórico de sensores.

  • Análise exploratória e detecção de anomalias
  • FMEA assistido por dados: criticidade e frequência de falhas
  • KPIs de confiabilidade: MTBF, MTTR, disponibilidade
  • Python, pandas, scikit-learn, Jupyter e Power BI

A camada que conversa com o chão de fábrica, validada em ambiente simulado.

  • Integração via OPC UA e MQTT com SCADA e sensores IoT
  • Gêmeo digital simplificado para testes e validação, sem planta real
  • Documentação da arquitetura de comunicação entre TA e TI

Camada de visualização em campo, construída sobre a mesma API do núcleo — sem criar dependência. Condicionada a tempo/recursos disponíveis da equipe.

  • Reconhecimento de equipamento via marcador ou visão computacional (Unity 3D + ARFoundation/Vuforia)
  • Exibição de dados operacionais em tempo real sobre o equipamento identificado
  • Testes de usabilidade (SUS) e avaliação ergonômica (ISO 9241 / NR-17)
  • MVP em tablet/smartphone; validação em smart glasses é etapa estendida, não obrigatória

Stack técnica

Tecnologia escolhida para o contexto, não pela moda

Ferramentas maduras, amplamente documentadas e adequadas ao porte de um projeto integrador de TI — sem exigir hardware especializado para a entrega principal.

Camada Tecnologias sugeridas
Frontend React, Vue ou Angular + biblioteca de gráficos (Recharts / D3)
Backend Node.js, Python (FastAPI/Django) ou Java (Spring Boot)
Banco de dados PostgreSQL (relacional) + InfluxDB/TimescaleDB (séries temporais)
Integração TA OPC UA, MQTT — broker Mosquitto ou EMQX
Nuvem AWS, Azure ou GCP — serviços gerenciados de banco de dados, mensageria e containers
Ciência de dados Python (pandas, scikit-learn), Jupyter, Power BI
RA (opcional) Unity 3D, ARFoundation, Vuforia
DevOps Docker, CI/CD via GitHub Actions ou GitLab CI

Limites do projeto

O que entra e o que fica de fora

Clareza de escopo evita retrabalho. O PetroSync é dimensionado para um projeto integrador acadêmico de TI — não para substituir infraestrutura industrial existente.

No escopo
  • Integração com dados simulados ou históricos de SCADA/IoT
  • Gêmeo digital simplificado em ambiente controlado
  • Modelos de detecção de anomalia e manutenção preditiva
  • Dashboard web hospedado em ambiente cloud
  • Documentação da arquitetura TI + TA
Fora do escopo
  • Testes em ambiente real de planta operante
  • Aquisição e configuração de hardware físico de sensores
  • Certificação ou homologação de segurança industrial (SIL, ATEX)
  • Substituição de sistemas SCADA legados

Riscos e restrições

Projeto permanece em fase teórica/exploratória, sem testes em planta real.
Validação da integração depende da disponibilidade de dados reais, simulados ou históricos de sensores/SCADA.
Equipe pode precisar de capacitação em protocolos industriais (OPC UA/MQTT) caso não haja domínio prévio.
Sistemas legados podem exigir adaptadores ou middlewares específicos para integração.
O módulo de Realidade Aumentada está sujeito a corte total caso o cronograma do núcleo não seja cumprido.
